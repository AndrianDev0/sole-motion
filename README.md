# Sole Motion

Интерактивный 3D-концепт магазина обуви на React, TypeScript и Three.js.

[Открыть демо](https://sole-motion-public.vercel.app/) · [Портфолио автора](https://andriandev0.github.io/)

Проект демонстрирует интерфейс и 3D-подачу товара. Наличие реальной оплаты и обработки заказов этим демо не заявляется.

## Локальный запуск

Требуются Node.js 22.13+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет сервер.

## Проверка и сборка

```bash
pnpm lint
pnpm build
```

Команды приведены для самостоятельного запуска; их наличие не означает, что проверки выполнены в вашем окружении.

## Технологии

React, TypeScript, Three.js, Tailwind CSS, Vite и vinext. Настройки публикации находятся в `vercel.json` и `vite.config.ts`.
